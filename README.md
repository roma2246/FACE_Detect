# EmoCam — распознавание эмоций по лицу с эмодзи

Веб-приложение: вы видите себя с веб-камеры, а над головой появляется эмодзи вашей эмоции.
Распознаются 5 эмоций: 😊 Happy, 😢 Sad, 😡 Angry, 😮 Surprise, 😐 Neutral.

```
ICT_ENDTERN/
├── front/                 React + Vite — интерфейс
│   └── src/
│       ├── App.jsx                видео, эмодзи над головой, вероятности, статистика
│       ├── TrainPanel.jsx         запись своих снимков и запуск дообучения
│       └── lib/
│           ├── useEmotionEngine.js  камера, детектор лиц, WebSocket, сглаживание
│           ├── faceCrop.js          вырезание лица -> 48x48 серое
│           └── emotions.js          классы, эмодзи, порог уверенности
└── back/                  Node.js — инференс и API
    ├── server.js              Express + WebSocket + ONNX Runtime
    ├── models/                emotion_cnn.pth / .onnx (и *_ft после дообучения)
    └── ml/                    обучение модели (Python, PyTorch)
        ├── model.py           архитектура CNN (1x48x48 -> 5 классов)
        ├── dataset.py         FER-2013, 5 классов, аугментация, веса классов
        ├── train.py           обучение, графики, матрица ошибок, экспорт в ONNX
        ├── finetune.py        дообучение на своих снимках с веб-камеры
        └── reports/           curves.png, confusion_matrix.png, metrics.json
```

## Как это работает

1. Браузер получает видео с камеры и находит лица (MediaPipe BlazeFace, работает локально).
2. Каждое лицо вырезается, сжимается до 48×48 в оттенках серого и по WebSocket уходит на Node-бэкенд (2304 байта на лицо).
3. Бэкенд выравнивает гистограмму и прогоняет лицо через CNN (ONNX Runtime, CPU, < 1 мс).
4. Вероятности усредняются по последним 8 кадрам; если уверенность ниже 0.4 — остаётся предыдущая эмоция. Эмодзи не мигает.

Всё работает локально, видео никуда не отправляется.

Если Node-бэкенд недоступен (например, в статическом деплое на Vercel), та же модель запускается
прямо в браузере через ONNX Runtime Web — в шапке появляется метка «в браузере». Дообучение на своём
лице в этом режиме недоступно: для него нужен локальный бэкенд с Python.

## Запуск

Нужны Node.js 20+ и Python 3.10+.

```bash
# 1. Бэкенд
cd back
npm install
npm start            # http://localhost:3001

# 2. Фронтенд (во втором терминале)
cd front
npm install
npm run dev          # http://localhost:5173
```

Откройте http://localhost:5173 и разрешите доступ к камере.

## Деплой на Vercel

Деплоится только `front/` как статический сайт (Root Directory = `front`, пресет Vite):

```bash
cd front
npx vercel --prod
```

## Обучение модели

Обученные веса уже лежат в `back/models/`. Чтобы обучить заново:

```bash
cd back/ml
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python train.py        # FER-2013 скачается автоматически (~60 МБ)
```

- Датасет: FER-2013 (48×48, серые), классы Disgust и Fear исключены → ~24 тыс. обучающих изображений.
- Валидация: 12% от train (стратифицированно); test (PublicTest + PrivateTest) — только для финальной оценки.
- Дисбаланс классов — веса в `CrossEntropyLoss`. Аугментация: отражение, поворот ±10°, сдвиг, масштаб, яркость/контраст.
- Adam (lr 1e-3) + ReduceLROnPlateau, батч 64, до 40 эпох, ранняя остановка, seed 42.

## Дообучение на своём лице

Прямо в интерфейсе, блок «Дообучить на моём лице»:

1. Выберите эмоцию, покажите её в камеру, нажмите «Записать» (40 кадров).
2. Повторите для остальных эмоций.
3. Нажмите «Дообучить» — бэкенд запустит `ml/finetune.py`, покажет прогресс и сам подхватит новую модель.

Свои снимки смешиваются с частью FER-2013, чтобы модель не разучилась на остальных людях.
Кнопка «вернуть базовую» откатывает к исходной модели. Снимки хранятся в `back/ml/data/custom/`.

## Ограничения

Модель предназначена для демонстрации и не оценивает реальное психологическое состояние человека.
FER-2013 — шумный датасет (люди сами согласны с разметкой примерно в 65% случаев).

Эмодзи — системные (Unicode), детектор лиц — MediaPipe BlazeFace (Apache 2.0).
